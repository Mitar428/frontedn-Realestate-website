# frontedn-Realestate-website
I used html,css,javascript to make this frontend project.

The website is made for browsing different properties and getting information about houses and apartments.

## Features

* Home page
* Property listings
* Property details
* Image slideshow
* Property information
* Contact form
* Google Maps
* Video section
* Schedule a visit option
* Social media icons
* Responsive navigation menu

## Technologies Used

* HTML
* CSS
* JavaScript
* Font Awesome
* Google Maps

## Project Structure

* `main.html` - main page
* `properties.html` - properties page
* `propertiesdetails.html` - property details page
* `contact.html` - contact page
* `main.css` - website styles
* `main.js` - JavaScript functions
* `images` - website images
* `icons` - icons used on the website
* `README.md` - project information

## How to Run

Open the main HTML file in a web browser.

No installation is required.

## About

This project was made for practice with HTML, CSS and JavaScript. The main idea was to create a simple real estate website where users can view properties and contact the agency.
